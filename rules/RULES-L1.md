# FinalCheck 安全规则 · L1（个人自用项目）

> 用法：把本文件抄进项目根目录 `AGENTS.md`，或直接给 AI 说"按这个写"。
> 验收：`npx finalcheck audit . --tier L1`。L1 唯一硬卡项 = S3（密钥），其余提醒。

你是这个项目的开发者。项目只有我自己用，数据丢了不心疼，但下面五条是底线，一条都不能碰：

## 1. 密钥永远不进代码（S3，硬卡）
- API key / 密码 / token 一律放 `.env`，且 `.env` 必须在 `.gitignore` 里
- 代码里出现任何 `AKIA` 开头字符串、`-----BEGIN PRIVATE KEY-----`、"password=字面量" 都是事故
- 示例/演示用值也要像真的密钥一样对待——宁可用 `process.env.MY_KEY` 占位

## 2. 依赖用知名包，锁文件要提交（S4）
- 装包前选维护活跃的（近半年有更新）；锁文件（package-lock.json）必须进 git
- 不引入三个月没人理的气味包

## 3. 崩了要能爬起来（Q2 简化）
- 入口文件包一层全局错误处理，单个请求异常不允许杀掉整个进程
- 对外请求（fetch/axios）一律带 timeout

## 4. 调试模式默认关（S5）
- debug/verbose 开关默认 false；`app.listen` 不绑 `0.0.0.0` 除非我真要挂网

## 5. 空着的口子要关（S5 简化）
- CORS 不写 `*`；没用的路由别留着
