---

# 何时用

- 完成一段开发、准备 commit / push 之前（交活闸）
- 用户要求"检查 / 验收 / 体检"项目时
- 下载或运行陌生开源项目之前（下载闸，若已配 hook 会自动触发）

# 怎么做

1. **定档**：个人自用=L1；挂公网有真实用户=L2；公司项目/收钱=L3。拿不准就按 L2 保守执行
2. **跑体检**：`node <FinalCheck 安装目录>/bin/finalcheck.js audit . --tier <档位> --interactive`（装好 bin 后可用 `npx finalcheck audit .`）
3. **结论=过** → 向用户汇报评分卡与覆盖范围，收工
4. **结论=拦 / 修完再过** → 逐条按报告里的"修复提示词"改代码 → **重跑直到 过**，或把修不掉的逐条向用户说明
5. **覆盖不足条目必须向用户转述**——那是"这次没查到的部分"，不等于"没有风险"

# 铁律

- 不许加 `finalcheck:allow` 豁免，除非用户明确同意且说明理由
- 每条发现要么修掉、要么向用户解释，禁止静默忽略
- 修完必须重跑验证，不许只改不验
